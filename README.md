## OpenWebMonitor 是做什么的，先确认自己用不用得上

它是一个装在电脑上的网页内容监控工具，Windows 和 macOS 都有。用法是添加网页地址，指定要盯的区域或关键词，页面内容发生变化后通过通知提醒你。和浏览器插件比，它不依赖打开一堆标签页，适合同时盯十几个页面的人。

实际被用在哪些地方，公开的功能介绍里列得比较实在：

- 商品价格回调和补货，尤其是差价上千的东西
- Steam 这类平台的折扣，等到心理价位再入手
- 活动报名人数、秒杀开始时间
- 官网公告、条款页、政策页的更新
- 自己维护的网站是否正常打开

它不适合的情况也说清楚。只是偶尔想看一眼某个页面，浏览器插件更省事，装个桌面软件纯属浪费。需要 7×24 小时不间断盯着、而你的电脑经常关机，这类本地工具也帮不上忙。桌面监控通常要靠软件保持运行才能持续检查，如果商品页没有写明云端代监控，就别指望关掉软件还能收到提醒。
